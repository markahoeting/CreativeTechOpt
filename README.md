# Creative Technology Portfolio Optimizer
### Higher Education Adobe & Canva License Assessment Platform
**Powered by Info-Tech Research Group**

---

## Overview

A web-based assessment tool that helps Higher Education CIOs and IT leaders evaluate whether to reduce Adobe Creative Campus licenses and supplement with Canva. Built with Flask and branded with Info-Tech Research Group colors.

**Brand Colors:**
- Primary: `#2676B7` (Mariner Blue)
- Accent: `#74A5CD` (Danube)
- Dark: `#02122B` (Tangaroa Navy)

---

## 6-Phase Assessment Workflow

| Phase | Description |
|-------|-------------|
| **1 — Institution Profiling** | Institution type, enrollment, tech environment, Adobe contract details |
| **2 — License & Usage Analysis** | License volumes, usage sliders (inactive/acrobat-only/light/power), app-level usage |
| **3 — User Segmentation Engine** | 6 user segments with headcount and department mapping |
| **4 — Academic Dependency Analysis** | Program dependencies, accreditation risk, faculty governance, change readiness |
| **5 — Financial Optimization Modeling** | 5 cost scenarios with interactive sliders, live calculations |
| **6 — Results Dashboard & Reports** | 6 charts, risk analysis, department recommendations, roadmap, executive brief |

## Local Development

### Prerequisites
- Python 3.10+
- pip

### Setup

```bash
# 1. Create virtual environment
python -m venv venv

# macOS / Linux
source venv/bin/activate

# Windows
venv\Scripts\activate

# 2. Install dependencies
pip install -r requirements.txt

# 3. Run the app
python app.py
```

Open http://localhost:5000

## Deploying to Render

### Option 1 — render.yaml (recommended)
1. Push this project to a GitHub repository
2. In Render Dashboard → **New** → **Blueprint**
3. Connect your GitHub repo
4. Render will auto-detect `render.yaml` and configure the service

### Option 2 — Manual Web Service
1. In Render Dashboard → **New** → **Web Service**
2. Connect your GitHub repo
3. Configure:
   - **Environment:** Python
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `gunicorn app:app --bind 0.0.0.0:$PORT --workers 2 --timeout 60`
   - **Plan:** Free

### Environment Variables (Render)
| Variable | Value |
|----------|-------|
| `PYTHON_VERSION` | `3.11.0` |
| `FLASK_ENV` | `production` |
| `SECRET_KEY` | *(auto-generated by render.yaml)* |

## API Endpoint

### `POST /api/calculate`
Accepts form data as JSON and returns full analysis results.

**Request Body (key fields):**
```json
{
  "inst_name": "State University",
  "adobe_total": 2000,
  "adobe_cost": 350000,
  "pct_inactive": 30,
  "pct_acrobat": 20,
  "pct_light": 25,
  "pct_power": 15,
  "sc_c_reduce": 40,
  "sc_c_canva": 35
}
```

**Response:**
```json
{
  "ok": true,
  "kpis": { "total_licenses": 2000, "inactive_count": 600, "annual_saving": 140000 },
  "scenarios": { "a": {...}, "b": {...}, "c": {...}, "d": {...}, "e": {...} },
  "risk_scores": { "Academic Disruption": 20, "Faculty Resistance": 50, ... },
  "segments": { "power": 120, "light": 350, ... },
  "dept_recs": [...]
}
```
